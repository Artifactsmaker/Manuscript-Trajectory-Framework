TrajectoryLab - Manuscript Positioning & Journal Matching

TrajectoryLab (formerly Universal Journal Review Simulator - UJRS) is an advanced, high-fidelity AI-powered simulation engine designed to replicate the rigorous editorial screening and peer-review workflows of top-tier global scientific journals (such as Nature, Science, IEEE Transactions, and ACM).

By employing a multi-role hybrid AI Editorial Board, TrajectoryLab evaluates draft manuscripts across eleven exhaustive academic phases. It provides objective, uncompromising assessments of publication readiness, mathematical/conceptual soundness, reproducibility, and strategically matches papers to optimal publication routes.

Key Features

Multi-Role Hybrid AI Editorial Board: Simulates distinct feedback profiles for an Associate Editor, a Technical Reviewer (Reviewer A), a Novelty Reviewer (Reviewer B), and a Reproducibility Reviewer (Reviewer C).

11-Phase Comprehensive Pipeline: Evaluates scientific quality systematically from raw data ingestion to the final editorial decision.

Dual-Language Peer Review Output: Supports high-fidelity English (default) and Vietnamese (optional) review generation.

Academic-Grade UI/UX: Responsive layout featuring real-time diagnostic logs, dynamic DNA metrics charts, visual probability distributions, and support for rendering complex mathematical formulations using LaTeX (via MathJax).

Export-Ready Output: Easily copy completed review reports in standard Academic Markdown or print directly to print-ready PDFs.

The 11-Phase Rigorous Evaluation Pipeline

Phase 0: Manuscript Genotype Analysis: Dynamically extracts the underlying structural "DNA" of the manuscript, classifying its category and measuring factors like formalization, engineering readiness, and vision magnitude.

Phase 1: Initial Desk Screening: Simulates the critical gatekeeping step. Analyzes scope fit, academic writing quality, and ethical compliance to generate a "Proceed to Review" or "Desk Reject" verdict.

Phase 2: Novelty Analysis: Evaluates originality against existing literature, conceptual/methodological contributions, and breakthrough potential.

Phase 3: Technical Review: Critically scrutinizes formal mathematical consistency, definition rigor, experimental design, and identifies minor/major concerns.

Phase 4: Reproducibility Review: Rates the availability of source code, datasets, benchmarks, and assigns a reproducibility index (High/Medium/Low).

Phase 5: Impact Analysis: Projects short-term and long-term scientific, practical, and cross-disciplinary impact vectors.

Phase 6: Journal Tier Simulation: Employs probabilistic models to estimate the manuscript's performance (Accept, Major/Minor Revision, Desk Reject) across Q1, Q2, and Q3 journal brackets.

Phase 7: Individual Reviewer Board Transcripts: Generates independent, objective feedback, highlighting specific strengths, critical deficiencies, and mandatory revisions from the 3 specialized reviewers.

Phase 8: Editorial Synthesized Opinion: Synthesizes an overall editorial score (0-100) alongside key reasons for accept/reject.

Phase 9: Strategic Submission Advisor: Suggests target repositories, specific Q1-Q3 journals, or open-access channels with custom AI confidence intervals.

Phase 10: AI Editorial Verdict: Delivers exactly one final operational decision: Accept, Minor Revision, Major Revision, or Reject.

Getting Started

Since TrajectoryLab is built using a Zero-Dependency Single-File Architecture, setting up and running the application takes seconds.

Quick Run

Download or copy the index.html file from this repository.

Double-click index.html to open it in any modern web browser (Chrome, Firefox, Safari, Edge).

(Optional but recommended) Click the ⚙️ icon on the top-right header to configure your personal Google Gemini API Key. If left empty, the application will default to the system-allocated runtime key.

Paste your manuscript details or load one of our pre-configured research demos to launch the simulator.
